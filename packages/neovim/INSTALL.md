## Installation Guide

### For Linux (Ubuntu/Debian/Fedora)
1. Install Neovim: `sudo apt install neovim` (Debian/Ubuntu) or `sudo dnf install neovim` (Fedora)
2. Copy `neovim/vaporsoft-dark.lua` and `neovim/vaporsoft-light.lua` to `~/.config/nvim/`
3. Add `require('vaporsoft-dark')` or `require('vaporsoft-light')` to your `init.lua`
4. Restart Neovim

### For Windows 11
1. Install [Neovim](https://github.com/neovim/neovim/releases/latest) via official installer
2. Copy `neovim\vaporsoft-dark.lua` and `neovim\vaporsoft-light.lua` to `%APPDATA%\nvim\`
3. Add `require('vaporsoft-dark')` or `require('vaporsoft-light')` to your `init.lua`
4. Restart Neovim
