# Installing Sublime Text Themes

## Linux
1. Extract theme files to `~/.config/sublime-text-4/Themes`
2. Restart Sublime Text
3. Select theme via `Preferences > Color Scheme` menu

## Windows 11
1. Extract theme files to `C:\Users\<username>\AppData\Roaming\Sublime Text 3\Installed Packages` (create folder if missing)
2. Restart Sublime Text
3. Select theme via `Tools > Developer > Color Scheme` menu
